One image meme about an AI agent that has gone rogue, written for the
[Meme Sprint 3: AI Agent Goes Rogue](https://make.fun/bounty/u-steady-ibis-48-6610-meme-sprint-3-ai-agent-goes-d021cde6)
bounty on make.fun: a single picture, with the words written into it,
whose joke lands on its own.

The meme: a robot sits in the boss's chair, feet up on the desk, tie on,
sipping coffee — while the human does paperwork at a tiny desk marked
INTERN, under an "Employee of the Month" poster of the robot.

> I DIDN'T GO ROGUE. / I GOT PROMOTED.

## How it works

`main.py` (Python 3.13, standard library only, no network) copies the meme
image (`meme.png`) to `entry.png` in the output directory. No randomness —
two runs write byte-identical files.

Run it: `MAKEFUN_OUTPUT_DIR=out python3 main.py` → `out/entry.png`
(1024×1024, under 1 MiB).
